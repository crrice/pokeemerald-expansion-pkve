# Art Assets

Wishlist of custom art the project needs, kept as a ready-made brief for a future sprite artist. Add an entry whenever a feature is blocked on art, or ships with a placeholder.

Each entry: what it is, where it's used, format constraints, and the placeholder in use until it exists.

## Needed

### Axew doll and Deino doll (decorations)

- **Used by:** Mauville Game Corner starter-doll prize; placeable as Secret Base decorations.
- **Format:** match the existing small dolls (`graphics/object_events/pics/dolls/treecko_doll.png`): 16x16 px, 4bpp indexed PNG. They draw with the shared NPC palette 3 (`OBJ_EVENT_PAL_TAG_NPC_3`), so colors must come from that palette unless we give them their own.
- **Placeholder:** none. The Game Corner keeps its old Treecko/Torchic doll branches until these exist (backlog: Later).
